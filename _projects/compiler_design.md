- Designed a compiler from scratch for a synthetic C-style programming language by performing lexical analysis (tokenizing) using ML-Lex, and parsing, semantic analysis (semantic checks) using ML-Yacc.
- Designed an unambiguous grammar from the EBNF, enforced type checking, and handled errors with structured error handling while parsing.
- Developed a stack-based push-down automaton AST executor for executing the Abstract Syntax Tree generated from the program, with support for control flow.
