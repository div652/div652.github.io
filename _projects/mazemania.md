Designed and developed a two-player competitive open-world online multi-player game from scratch in C++ using SDL2.0 library for graphic rendering and I/O.

- Handled data transfer using Socket-Level Programming over UDP with a server-client model.
- Created an 80k-tile Open-World Tilemap based on the IIT Delhi campus (200x400) using TILED and PyxelArt, implementing collision detection and scrolling backgrounds.
- Optimized tile rendering with multithreading using pthreads for smooth graphics and efficient performance.
