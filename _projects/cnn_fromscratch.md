- Built a 3-layer CNN from scratch (127k params; mixed 3x3/5x5 kernels) by implementing Conv2D, FC, Pooling, and Activation Layers, trained with Adam+CosineLR.
- Implemented a CNN Pipeline using PyTorch with ~220k params, adding Data Augmentation, Dropout layers, and GPU training.
- Achieved 62.4% accuracy from the scratch implementation and 71.8% from the PyTorch implementation on 50k images.
