Made a movie recommendation app from Bootstrap Flask in the frontend and a PostgreSQL backend.
- Performed cleaning and normalization on IMDb's public dataset with >106.2M records (8.3GB to 5.2GB) using ER modeling, reducing storage by 37% to make a database.
- Created optimized PostgreSQL pipelines (cleaning, joins, aggregates) for database search, updating, and powering a recommender system based on user's past ratings across 10.6M titles.
- Cut search latency from 30s+ to <2s by adding B-tree indexes, CTEs, triggers, and Full Text Search queries to improve performance.
