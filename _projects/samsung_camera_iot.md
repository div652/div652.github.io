Built the Camera IoT service for Samsung Displays with 30-fps live-streaming and on-device object detection, serving 60M+ devices.
- Optimized MobileNet-v1 for sound-event detection to reduce size from 18.3 to 13.7 MB via mixed-precision quantization.
- Developed on-device recognition for 250+ landmarks for Tizen XR using EfficientDet, achieving 78.5% accuracy.
- Improved KeyBERT based Sentence Keyword Extraction by knowledge distillation, raising mAP from 0.438 to 0.485.
